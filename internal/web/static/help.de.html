Erste Schritte

EdgeTAK ist ein TAK-Server: ATAK-, WinTAK-, TAKX- und iTAK-Geräte verbinden sich damit, um Positionen, Markierungen, Chat, Dateien und Video zu teilen. Die Konsole ist in der oberen Leiste in Bereiche gegliedert (Übersicht, Personen, Daten, Nachrichten, Server); die Seiten jedes Bereichs stehen in der Zeile darunter.

Die ersten Schritte

  1. Admin-Passwort ändern: Klicken Sie unter Benutzer auf Passwort bei admin.
  2. Gruppen erstellen unter Gruppen, zum Beispiel Cyan und Command. Geräte sehen nur den Verkehr der Gruppen, die sie gemeinsam haben.
  3. Benutzer erstellen unter Benutzer und ihre Gruppen ankreuzen. Geben Sie jeder Person einen eigenen Benutzer, damit Sie ein Gerät sperren können, ohne die anderen zu beeinträchtigen.
  4. Serveradresse prüfen: Auf einem lokalen Server verwenden Pakete und QR-Codes die Adresse, unter der Sie diese Konsole geöffnet haben. Öffnen Sie sie daher unter der Adresse, die die Geräte verwenden (nicht localhost). Mit Let's Encrypt verwenden sie den Öffentlichen Host aus der Übersicht.
  5. Gerät verbinden: Erstellen Sie unter Verbinden einen QR-Code für einen Benutzer und scannen Sie ihn mit der Kamera des Telefons. Siehe Geräte verbinden.

Tipps

  • Die Karte neben jeder Seite zeigt die Geräte live. Karte in der oberen Leiste blendet sie ein oder aus.
  • Ihre eigenen Geräte, Zertifikate und Ihr Passwort finden Sie unter Mein Konto.
  • Die Design-Schaltfläche in der oberen Leiste wechselt zwischen Auto (die Hell- oder Dunkel-Einstellung Ihres Geräts), Hell und Dunkel.
  • Jede Ihrer Änderungen wird im Audit-Protokoll festgehalten.

Übersicht

Der Zustand des Servers auf einen Blick: verbundene Geräte, Nachrichten, Probleme, die Aufmerksamkeit brauchen, und Updates.

  • Probleme ganz oben listet alles auf, was nicht stimmt: eine volle Festplatte, bald ablaufende Zertifikate, eine unterbrochene Föderationsverbindung.
  • Server zeigt die Version, die Adresse, die die Geräte verwenden (Öffentlicher Host), und die Ports.
  • EdgeTAK-Updates: Nach Updates suchen, dann Installieren. EdgeTAK startet sich selbst neu; die Geräte verbinden sich von allein wieder. Kreuzen Sie Vorabversionen einbeziehen nur auf Testservern an.
  • Verbundene Clients listet jedes Gerät mit Benutzer, Gruppen und Verbindung auf. Von hier aus können Sie ein Gerät trennen.

Zustand

Diagramme der letzten Stunde bis 24 Stunden: CPU, Arbeitsspeicher, Festplatte, Netzwerk, Temperatur (auf einem Raspberry Pi), verbundene Geräte, Nachrichten und Videobandbreite, mit Warnungen bei voller Festplatte, Überhitzung oder verworfenen Nachrichten.

Die Tabelle Geräte listet für jedes Gerät den Akkustand (und wie schnell er sinkt), die letzte Meldung, den GPS-Fix und die Verbindung auf, die schlimmsten Probleme zuerst. So erkennen Sie ein Telefon, dessen Akku gleich leer ist, bevor es wegfällt.

Benutzer

Alle, die sich anmelden: die Geräte der Personen, die Konsole und die Kontoseite.

Benutzer hinzufügen

  1. Geben Sie einen Benutzernamen und ein Passwort (8 Zeichen oder mehr) ein.
  2. Kreuzen Sie die Gruppen an. Keine Gruppe bedeutet __ANON__, geteilt mit anonymen Geräten.
  3. Kreuzen Sie Administrator nur für Personen an, die den Server betreiben.
  4. Erstellen, dann das Gerät der Person mit QR in ihrer Zeile verbinden.

Die Schaltflächen bei jedem Benutzer

  • Gruppen: welche Gruppen und in welche Richtung: ein + aus (der Normalfall), ein (nur empfangen) oder aus (nur senden). Änderungen erreichen verbundene Geräte sofort.
  • Passwort setzt ein neues. Zum Admin machen / Adminrechte entziehen ändert die Rolle.
  • Deaktivieren sperrt die Person sofort (Anmeldungen, Zertifikate, verbundene Geräte), behält aber das Konto; Aktivieren stellt alles wieder her. Ziehen Sie das dem Löschen vor.
  • QR erstellt einen QR-Code, der das Telefon der Person verbindet (siehe Geräte verbinden). Paket lädt ein Verbindungspaket herunter; .p12 ausstellen ein Zertifikat für von Hand eingerichtete Clients.
  • QR-Bogen drucken… (über der Liste) druckt eine beschriftete QR-Karte für jeden gewählten Benutzer oder eine ganze Gruppe.

Ebenfalls auf dieser Seite

  • Zwei-Faktor-Anmeldung für Ihr eigenes Konto: nach dem Passwort ein Code aus einer Authenticator-App. TAK-Apps sind davon nicht betroffen.
  • Verzeichnisanmeldung (LDAP / Active Directory): Personen melden sich mit ihrem Verzeichniskonto an, und Verzeichnisgruppen werden zu EdgeTAK-Gruppen. Verwenden Sie vor dem Speichern Diese Einstellungen testen.

Gruppen und Geräteprofile

Gruppen bestimmen, wer was sieht: Ein Gerät empfängt den Verkehr, der an die Gruppen gesendet wird, in denen es ein ist, und sein eigener Verkehr geht an die Gruppen, in denen es aus ist. Benutzer können Gruppen auf ihrem Gerät mit Channels in ATAK ein- und ausschalten.

  • Gruppe erstellen mit Name und Beschreibung; Mitglieder legen Sie unter Benutzer oder hier mit der Schaltfläche der Gruppe fest.
  • Wenn Sie eine Gruppe löschen, wird sie bei ihren Mitgliedern entfernt.

Geräteprofile

Einstellungen und Dateien, die an die Geräte der Mitglieder einer Gruppe (oder aller Benutzer) gesendet werden: ATAK-Einstellungen (Schlüssel, Typ und Wert), .pref-Dateien, Plugin-APKs, Kartenquellen und Ebenen.

  • Geräte erhalten sie bei der Einrichtung und bei jeder Verbindung, wenn sich das Profil geändert hat.
  • Jetzt senden erreicht Geräte, die bereits verbunden sind. Herunterladen zeigt genau, was die Geräte erhalten.

Veranstaltungen

Ein zeitlich begrenzter Einsatz (eine Suche, eine Übung, ein Rennen) mit eigener Gruppe und auf Wunsch einer Data-Sync-Mission. Personen treten bei, indem sie einen QR-Code scannen, und wenn er endet, wird alles aufgeräumt.

  1. Neue Veranstaltung: ein Name, wann sie endet und wie Personen beitreten:
    • Jede Person registriert sich: Der QR-Code öffnet eine Registrierungsseite; jede Person wählt einen Namen und erhält ein eigenes Konto (begrenzen Sie die Anzahl mit Höchstens … Personen).
    • Ein gemeinsames Konto: Der QR-Code verbindet ATAK sofort; alle Geräte verwenden dasselbe Konto. Am schnellsten für spontan Hinzukommende.
  2. Zeigen Sie den QR-Code oder verwenden Sie Beitrittsblatt drucken, um es am Check-in-Punkt auszuhängen.
  3. Wenn die Veranstaltung endet (zur festgelegten Zeit oder mit Jetzt beenden), werden ihre Konten gelöscht, ihre Geräte getrennt und ihre Gruppe entfernt. Die Mission bleibt zur Auswertung erhalten.

Ende ändern ändert, wann sie endet. Paket liefert ein Verbindungspaket für das gemeinsame Konto.

Registrierungen

Lassen Sie Personen ihre Konten auf der Registrierungsseite selbst erstellen, statt jedes einzeln anzulegen.

  • Einladungslinks: Wählen Sie die Gruppen, wie viele Personen ihn nutzen dürfen (0 = unbegrenzt) und wie lange er gilt, und teilen Sie dann den Link oder seinen QR-Code. Wer ihn hat, erhält sofort ein Konto in diesen Gruppen.
  • Registrierung ohne Einladung: Aus (nur Einladungen, die Voreinstellung), Freigabe (Anfragen warten unter Offene Anfragen auf Ihre Freigabe) oder Offen (jeder, der den Server erreicht). Verwenden Sie „Offen“ nur dort, wo jeder beitreten darf.

Nach der Registrierung sehen Personen einen QR-Code, der ihr Telefon verbindet, und Verbindungspakete für jede App.

Zertifikate

Geräte verbinden sich mit einem Zertifikat, das EdgeTAK bei ihrer Einrichtung ausgestellt hat. Diese Seite listet alle auf.

  • Widerrufen Sie das Zertifikat eines verlorenen Geräts: Es wird getrennt und kann sich nicht mehr verbinden. Die anderen Geräte des Benutzers funktionieren weiter.
  • Serverzertifikate zeigt, wann die CA, das Serverzertifikat und ein etwaiges Let's-Encrypt-Zertifikat ablaufen und wie jedes erneuert wird.
  • Gerätezertifikate werden vor ihrem Ablauf markiert (standardmäßig 30 Tage); hier legen Sie fest, wie lange neue gültig sind. Ein Gerät erneuert sein Zertifikat, indem es neu eingerichtet wird (ein neuer QR-Code oder ein neues Paket).

Datenpakete

Über den Server geteilte Dateien: was Geräte mit Send → Server in ATAK hochladen und was Sie hier hochladen. Jedes ist für die Gruppen der Person sichtbar, die es hochgeladen hat, sofern Sie keine anderen wählen.

  • Pakete hochladen, suchen, herunterladen und löschen.
  • Gruppen legt fest, welche Gruppen ein Paket sehen und herunterladen können. Beim Hochladen hier wählen Sie sie unter Verfügbar für. Geräte, die ein Paket bereits heruntergeladen haben, behalten ihre Kopie.
  • Auf der Karte zeigen zeichnet die Markierungen, Routen, Formen und etwaige KML-, KMZ- oder GeoJSON-Daten eines Pakets auf die Karte der Konsole.
  • Um ein Paket an Geräte zu senden, verwenden Sie Senden.

Missionen (Data Sync)

Data-Sync-Missionen sind gemeinsame Arbeitsbereiche: Kartenobjekte und Dateien, die das Gerät jedes Abonnenten synchron hält, wobei Änderungen live übertragen werden. Sie werden meist in ATAK, WinTAK oder iTAK erstellt (Data Sync); diese Seite verwaltet sie.

  • Sehen Sie Abonnenten und ihre Rollen, die Objekte und Dateien, das Änderungsprotokoll und die Einladungen.
  • Auf der Karte zeigen zeichnet die Objekte einer Mission; Exportieren lädt sie herunter.
  • Eine Mission ist für die Gruppen sichtbar, für die sie erstellt wurde. Eine Veranstaltung kann eine für ihre Gruppe erstellen.

Karten: Zeichnungen und Offline-Karten

Zeichnungen

Zeichnen Sie Markierungen, Routen, Flächen und Kreise auf die Karte der Konsole; sie erscheinen auf den Karten der Geräte wie Objekte, die ein Teammitglied gesetzt hat, für alle Geräte oder für gewählte Gruppen. Geräte, die ausgeschaltet waren, erhalten sie bei der Verbindung; Bearbeiten oder Löschen aktualisiert die Geräte.

Offline-Karten

  1. Erstellen oder besorgen Sie eine MBTiles-Datei mit Rasterkacheln (QGIS, MOBAC, gdal und Ähnliches).
  2. Laden Sie sie hier hoch oder kopieren Sie große Dateien in den Ordner maps des Servers (auf der Seite angezeigt) und verwenden Sie Ordner neu einlesen.
  3. Sie wird zur Grundkarte in der Konsole, und ATAK-Geräte erhalten sie bei der Verbindung als Kartenquelle, sodass Karten ohne Internet funktionieren.

Ihre eigenen Kachelquellen (und ATAK-Kartenquelldateien im Format .xml) finden Sie unter Kartenquellen direkt auf der Karte; kreuzen Sie An ATAK-Geräte senden an, um eine davon zu den Kartenlisten der Geräte hinzuzufügen.

Ebenen

Senden Sie Kartenebenen (Grenzen, Suchsektoren, Routen, Punkte) an Geräte, ohne Dateien von Hand weiterzugeben.

  1. Importieren Sie eine KML-, KMZ- oder GeoJSON-Datei, benennen Sie sie und wählen Sie die Gruppen, deren Geräte sie erhalten (keine = alle Geräte).
  2. Verbundene Geräte erhalten sie sofort als eine Ebene im Overlay Manager von ATAK; Geräte, die ausgeschaltet waren, erhalten sie bei der Verbindung.
  3. Datei ersetzen sendet eine neue Version, die die alte ersetzt; Senden beenden pausiert sie.

ATAK lässt sich nicht anweisen, eine Ebene zu entfernen; Löschen beendet daher nur das Senden durch EdgeTAK, und die Personen entfernen sie auf ihrem Gerät.

Plugins

Ein Update-Server für ATAK wie der von tak.gov: Geräte installieren und aktualisieren Plugins und Apps über den Bildschirm Plugins in ATAK.

  • Hochladen von Plugin- oder App-APKs. Builds für mehrere ATAK-Versionen können nebeneinander liegen; jedes Gerät erhält den Build für seine Version (oder die nächstältere).
  • Geräte werden automatisch auf diesen Update-Server verwiesen (Geräte auf diesen Update-Server verweisen).
  • Wenn eine App in ATAK als Plugin erscheint (oder umgekehrt), verwenden Sie Als App behandeln / Als Plugin behandeln.
  • Plugins von tak.gov: Verknüpfen Sie ein tak.gov-Konto, wählen Sie die ATAK-Version und fügen Sie Plugins mit Hinzufügen hinzu, ohne sie selbst herunterzuladen.

Video

Video-Feeds für den Video Player von ATAK und WinTAK, nach Gruppe beschränkt.

  • Veröffentlichen: Senden Sie einen Stream mit einem beliebigen EdgeTAK-Benutzernamen und -Passwort, z. B. rtsp://USER:PASSWORD@server:8554/NAME (RTMP und SRT funktionieren ebenfalls). Er erscheint sofort auf dieser Seite.
  • Als Feed speichern benennt ihn, legt fest, wer ihn ansehen darf, und kann ihm eine Kartenposition geben (eine Kameramarkierung auf den Geräten).
  • Ansehen: Öffnen Sie auf Geräten den Video Player und importieren Sie vom Server; in der Konsole Ansehen.
  • Veröffentlichen ohne Anmeldung ist für Kameras, die sich nicht anmelden können: Erlauben Sie es nur für benannte Feeds.
  • Aufnahme (standardmäßig aus) bewahrt Streams eine festgelegte Anzahl von Tagen auf; Sie können sie unter Aufnahmen abspielen oder herunterladen.
  • Die Karte MediaMTX aktualisiert den Videoserver oder startet ihn neu.

Senden

Senden Sie eine Chatnachricht oder ein Datenpaket an alle, an gewählte Gruppen oder an gewählte Geräte.

  • Wählen Sie die Empfänger, schreiben Sie dann die Nachricht oder wählen Sie ein Datenpaket (einschließlich Einstellungspaketen im Format .pref).
  • Server-Kontakt: Der Server kann auf den Geräten als HQ-Kontakt erscheinen; Antworten auf seine Nachrichten landen im Posteingang.
  • Geplante Sendungen: eine Nachricht oder ein Paket zu einer festgelegten Zeit, einmalig oder wiederholt (alle paar Stunden, täglich, werktags, an gewählten Tagen).
  • Gesendet listet auf, was verschickt wurde.

Chat-Protokoll

Standardmäßig aus. Wenn es eingeschaltet ist, zeichnet es den über den Server gesendeten Chat auf (All Chat Rooms, Team- und Gruppenchats, Einzelnachrichten), für Nachbesprechungen.

Durchsuchen Sie es, filtern Sie nach Unterhaltung, Absender und Zeit und exportieren Sie es als CSV oder JSON. Wie lange Nachrichten aufbewahrt werden, legen Sie unter Einstellungen → Datenaufbewahrung fest.

Geräte verbinden

Wege, ein Gerät auf den Server zu bringen, der einfachste zuerst.

QR-Code (ATAK)

  1. Wählen Sie auf dieser Seite (oder mit QR neben einem Benutzer unter Benutzer) den Benutzer, wie lange der Code gilt und ob er für ein einzelnes Gerät ist.
  2. QR-Code erstellen und mit der Kamera des Telefons scannen. ATAK öffnet sich und verbindet sich als dieser Benutzer. Niemand tippt ein Passwort ein.
  • Mit Let's Encrypt bindet sich ATAK mit dem Code ein. Auf einem lokalen Server lädt es stattdessen ein Verbindungspaket (über Port 8080) mit einem Zertifikat herunter; verwenden Sie solche Codes in vertrauenswürdigen Netzen.
  • Bis zu seinem Ablauf ist der Code wie ein Passwort: Veröffentlichen Sie ihn nicht. Codes mit Nur ein Gerät funktionieren 10 Minuten nach ihrer ersten Verwendung nicht mehr.
  • Verlorenes oder neues Telefon: Kreuzen Sie Neues Telefon: seine Geräte ersetzen an. Wenn das neue Telefon den Code scannt, werden die anderen Geräte des Benutzers getrennt (Sie bestätigen vorher; bis zum Scan passiert nichts).
  • QR-Bogen drucken… erstellt für eine Einweisung eine Karte pro Benutzer.
  • iTAK: Wählen Sie iTAK unter App. Mit Let's Encrypt scannt iTAK den Code (Settings → Network → Servers → + → Scan QR), meldet sich an und bindet sich mit dem darin enthaltenen Einmalcode selbst ein. Auf einem lokalen Server lädt die Kamera des iPhones stattdessen ein Paket herunter, das Sie in iTAK mit Upload Server Package hinzufügen.

Die Code-Liste

Wird live aktualisiert. Geräte zeigt, was jeder Code eingerichtet hat: online mit dem Rufzeichen, offline, widerrufen oder nie verbunden. Wenn ein Telefon den Code gescannt hat, das bereits als jemand anderes mit diesem Server verbunden war, starten Sie ATAK neu. Widerrufen stoppt einen Code; Trennen trennt außerdem die Geräte, die er eingerichtet hat.

Andere Wege

  • Verbindungspaket (jede App): Laden Sie es hier herunter und importieren Sie es auf dem Gerät. Mit gewähltem Benutzer enthält es ein Zertifikat für diesen, sodass sich die App ohne Anmeldung verbindet (eines pro Gerät; widerrufen Sie es unter Zertifikate). Ohne Benutzer fragen ATAK, WinTAK und TAKX nach Benutzername und Passwort und binden sich ein. Für iTAK wählen Sie iTAK.
  • Adresse eintippen (Server mit Let's Encrypt): Fügen Sie den Server in der App hinzu, schalten Sie Use authentication und Enroll for client certificate ein und geben Sie Benutzername und Passwort ein.
  • Die Anmeldeseite für Benutzer (Link unten) lässt Personen ihren eigenen QR-Code und ihre Pakete abrufen.

Ebenfalls hier

  • Positionsverlauf: Zeichnen Sie die Wege der Geräte auf (standardmäßig aus) für Spuren, Wiedergabe und KML/GPX-Export, über die Schaltfläche Verlauf der Karte.
  • Kartenquellen: Kachelquellen, die an die Kartenlisten der Geräte gesendet werden.

Föderation

Verbinden Sie diesen Server mit einem TAK Server oder einem anderen EdgeTAK, damit die Geräte beider Seiten gegenseitig Positionen, Markierungen und Chat sehen und die Datenpakete der anderen Seite erhalten.

Mit einem TAK Server verbinden

  1. Mit einem Server verbinden, seine Adresse eingeben und wählen, wie die Anmeldung erfolgt: ein Zertifikat (Port 9001; der TAK Server muss der CA von EdgeTAK vertrauen, was TAK Server EdgeTAK vertrauen lassen mit dessen Admin-Anmeldung erledigt) oder ein Föderationstoken (Port 9002).
  2. Seine CA: Vom Server abrufen, den Fingerabdruck mit dem Administrator des Servers abgleichen und ihr vertrauen.
  3. Speichern. Die Liste zeigt den Zustand der Verbindung und die Nachrichtenzahlen.

Andere Server verbinden lassen

Schalten Sie Anderen Servern Verbindungen erlauben auf Port 9001 ein. Ein Server, der sich verbindet, wartet unter Wartet auf Freigabe; prüfen Sie seinen Fingerabdruck und klicken Sie dann auf Freigeben.

Geben Sie auf einem TAK Server mit LDAP dem Föderationspartner EdgeTAK eine der Gruppen Ihrer Benutzer (TAK-Server-Gruppen für EdgeTAK), sonst fließt kein Verkehr.

Einstellungen

  • Notfallalarme: Wenn jemand den Notfallknopf von ATAK drückt, zeigt jede geöffnete Konsole ein rotes Banner und gibt einen Alarmton aus, bis der Alarm bestätigt wird. Das Protokoll finden Sie hier.
  • Alarme bei Kontaktverlust: ein gelber Alarm mit der letzten Position, wenn ein Gerät keine Meldungen mehr sendet (nicht, wenn sich jemand absichtlich abmeldet). Zum Ausschalten das Häkchen entfernen.
  • Geofences: Zeichnen Sie eine Fläche oder einen Kreis und erhalten Sie einen Alarm, wenn Geräte sie betreten oder verlassen.
  • Logo: Logo hochladen… setzt das Logo Ihrer Organisation an die Stelle des ◆-Zeichens in der Konsole, auf den Anmelde-, Registrierungs- und Kontoseiten und auf gedruckten QR-Bögen und erzeugt daraus die Symbole für den Browser-Tab und die installierte App. PNG, JPEG oder WebP; Entfernen stellt die Voreinstellung wieder her.
  • Unverschlüsseltes TCP: Schalten Sie Port 8087 (unverschlüsselt, anonyme Geräte, die nur __ANON__ sehen) ohne Neustart ein oder aus. Das Ausschalten schließt den Port und trennt diese Geräte. Wenn der Server eine Firewall hat, öffnen Sie 8087 auch dort (sudo ufw allow 8087/tcp).
  • Let's Encrypt: Geben Sie einen Domainnamen ein, dessen DNS-Eintrag auf diesen Server zeigt (und optional eine E-Mail-Adresse), dann Einschalten. EdgeTAK startet neu und beantragt ein Let's-Encrypt-Zertifikat für den Einbindungsport (8446), sodass Apps sich per Schnellverbindung nur mit Adresse, Benutzername und Passwort verbinden. Port 80 muss zum Internet offen sein, in der Firewall des Servers und der des Cloud-Anbieters. Die Domain wird zum öffentlichen Host; zuvor erstellte Verbindungspakete und QR-Codes behalten die alte Adresse. Ausschalten kehrt zum EdgeTAK-Zertifikat zurück.
  • Mesh-Brücke: verbindet das Mesh von ATAK (Geräte, die Positionen und Chat per Multicast über WLAN oder MANET-Funkgeräte teilen, ohne Server) mit EdgeTAK. Kreuzen Sie die Schnittstelle an, an der die Funkgeräte hängen, wählen Sie die Gruppe, an die Empfangenes geht, und die Gruppen, die zurückgesendet werden, sowie was gesendet wird (Positionen, Chat, Notfälle, Zeichnungen). Funkteams und Serverbenutzer sehen sich dann gegenseitig, und Funkgeräte können Direktchats an Serverbenutzer senden.
  • ZeroTier: Bringen Sie den Server in ein ZeroTier-Netz, damit Geräte ihn von überall erreichen, ohne Router-Ports zu öffnen. ZeroTier installieren, Ihrem Netz über seine ID beitreten und dann den Knoten dieses Servers in ZeroTier Central autorisieren. Für Geräte verwenden neben seiner ZeroTier-Adresse lässt die Pakete und QR-Codes der Seite „Verbinden“ dorthin zeigen.
  • Fernzugriff (FRP): Erreichen Sie den Server von überall, ohne Router-Ports zu öffnen. Sie brauchen einen FRP-Server (frps) auf einem VPS oder einen Relay-Dienst. Fernzugriff einrichten, seine frpc.toml einfügen oder laden (oder Mit einer Vorlage beginnen und Server und Token eintragen), speichern und Verbinden. EdgeTAK lädt frpc herunter und hält es am Laufen. Für Geräte verwenden lässt Pakete und QR-Codes auf den FRP-Server zeigen.
  • Flugzeuge und Schiffe: Live-Flugzeuge (ADS-B, von adsb.lol, adsb.fi oder einer eigenen URL: die aircraft.json Ihres eigenen Empfängers oder eine andere API, mit deren API-Schlüssel in einem Header oder in der URL) und Schiffe (AIS, von aisstream.io mit einem kostenlosen API-Schlüssel) in einem Gebiet, als Kartenmarkierungen an die Geräte gesendet. Legen Sie den Mittelpunkt fest (oder Kartenmitte verwenden) und dann für jeden Feed den Radius, ob er gesendet wird und an welche Gruppen. Sie erscheinen auch auf der Karte der Konsole als Ebenen Flugzeuge und Schiffe.
  • Anmeldeschutz: sperrt eine Adresse nach zu vielen falschen Passwörtern. Tragen Sie Ihre eigenen Netze unter Nie sperren ein und heben Sie Sperren hier auf.
  • Datenaufbewahrung: wie lange Pakete, Missionen, Nachrichten, das Chat-Protokoll und das Audit-Protokoll aufbewahrt werden. Vor dem Speichern wird angezeigt, was entfernt würde.
  • Sicherung und Wiederherstellung: Laden Sie eine Sicherung herunter (oder planen Sie Sicherungen) und stellen Sie eine auf diesem oder einem neuen Server wieder her.

Webhooks

Senden Sie Alarme an Discord, Slack, Microsoft Teams, ntfy (Benachrichtigungen auf dem Telefon) oder eine beliebige URL, damit man auch bei geschlossener Konsole davon erfährt.

  1. Besorgen Sie sich beim Dienst eine Webhook-URL (die Seite enthält die Schritte für jeden Dienst).
  2. Webhook hinzufügen, den Dienst wählen, die URL einfügen und die Alarme wählen: Notfälle, Geofences, Kontaktverlust, Registrierungen, administrative Änderungen, Serverzustand, gesperrte Anmeldungen.
  3. Speichern und auf Test senden klicken.

Beschränken Sie einen Webhook auf Gruppen, um nur von den Geräten dieser Benutzer zu erfahren.

Erweiterungen

Server-Plugins, die EdgeTAK um Funktionen erweitern, etwa Tracker- oder Funkbrücken, Exporte und Integrationen. Eine Erweiterung ist ein Programm (eine .zip mit einer plugin.json), das EdgeTAK ausführt und am Laufen hält.

  1. Erweiterung installieren… und die .zip wählen. Wenn Sie eine neuere Version einer installierten Erweiterung installieren, wird sie aktualisiert und behält ihre Daten.
  2. Prüfen Sie, was sie darf: CoT empfangen, CoT senden, Serverdaten lesen (Gruppen, Geräte, Missionen, Positionsverlauf) oder hier eine Seite anzeigen.
  3. Wählen Sie die Gruppen, aus denen sie CoT empfängt und an die sie CoT sendet. Sie funktionieren wie die Gruppen eines Benutzers.
  4. Starten Sie sie. EdgeTAK startet sie erneut, wenn sie anhält, und wenn EdgeTAK startet.
  • Seite öffnen zeigt ihre Seite mit ihren Einstellungen. Protokoll zeigt ihre Ausgaben, die erste Anlaufstelle, wenn sie sich falsch verhält.
  • Sie läuft auf dem Server wie jedes andere Programm; installieren Sie daher nur Erweiterungen, denen Sie vertrauen.
  • Wie Sie selbst eine schreiben, steht im Leitfaden für Erweiterungen (auf Englisch).

Audit-Protokoll

Jede Änderung durch einen Administrator, mit wer, von wo, was und ob es geklappt hat; außerdem Anmeldungen, fehlgeschlagene Anmeldungen, gesperrte Adressen, Geräteeinbindungen und verwendete QR-Codes. Passwörter und Schlüssel werden nie aufgezeichnet.

Durchsuchen Sie es, zeigen Sie nur Fehlschläge an und laden Sie es als CSV herunter. Wie lange es aufbewahrt wird, steht unter Einstellungen → Datenaufbewahrung (standardmäßig für immer).

Protokoll leeren… löscht nach Ihrer Bestätigung alle Einträge; laden Sie vorher eine CSV herunter, wenn Sie sie brauchen. Das Leeren selbst bleibt als erster Eintrag des neuen Protokolls stehen.

Simulator

Lasttests: Simulierte Geräte verbinden sich wie ATAK, bewegen sich und senden Positionen (und Chat), damit Sie vor einer großen Veranstaltung sehen, wie der Server die Last bewältigt.

  • Wählen Sie, wie viele Geräte, wie schnell sie beitreten, wie oft sie melden und wie lange der Test läuft, und verfolgen Sie dann live Verbindungen, Ereignisse pro Sekunde, Weiterleitungszeit, CPU und Arbeitsspeicher.
  • Sie verwenden ein temporäres Konto in der Gruppe Simulator, sodass echte Geräte sie nicht sehen; es wird entfernt, wenn der Test endet.
  • Der Verkehr wächst mit dem Quadrat der Geräteanzahl; beginnen Sie auf einem Raspberry Pi klein. Schalten Sie vorher den Positionsverlauf aus, wenn sie nicht aufgezeichnet werden sollen.

Mein Konto und Zwei-Faktor-Anmeldung

Alle melden sich auf derselben Seite an: Administratoren gelangen weiter zu dieser Konsole, Benutzer zu ihrer Kontoseite, wo sie einen QR-Code für ihr Telefon und Verbindungspakete erhalten, ihre Geräte und Zertifikate sehen, das Zertifikat eines verlorenen Geräts widerrufen und ihr Passwort ändern.

Zwei-Faktor-Anmeldung (optional): Schalten Sie sie auf der Kontoseite ein (oder für sich selbst unter Benutzer), scannen Sie den Code mit einer Authenticator-App und bewahren Sie die Wiederherstellungscodes auf. TAK-Apps verwenden weiterhin das Passwort. Wenn jemand sein Telefon verliert, kann ein Admin unter „Benutzer“ 2FA zurücksetzen.

Fehlerbehebung

  • Ein Gerät kann sich nicht verbinden: Prüfen Sie, ob der Öffentliche Host in der Übersicht eine Adresse ist, die das Telefon erreichen kann, und ob die Ports offen sind (8089 für Geräte, 8443 für die API, 8446 für die Einrichtung). Ist der Benutzer deaktiviert oder das Zertifikat widerrufen?
  • Ein QR-Code zeigt „nie verbunden“: Das Telefon war wahrscheinlich bereits als jemand anderes mit diesem Server verbunden. Starten Sie ATAK neu (oder entfernen Sie den Server in ATAK und scannen Sie erneut).
  • Geräte sehen sich nicht: Sie brauchen eine gemeinsame Gruppe („ein“ auf der einen Seite, „aus“ auf der anderen). Prüfen Sie Gruppen bei jedem Benutzer.
  • Jemand ist ausgesperrt: Sehen Sie unter Derzeit gesperrt in Einstellungen → Anmeldeschutz nach.
  • Sehen, was ein Gerät tut: Setzen Sie log_level auf debug und verfolgen Sie das Serverprotokoll (journalctl -u edgetak -f); jede Anfrage wird aufgeführt.
