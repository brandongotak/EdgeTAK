Premiers pas

EdgeTAK est un serveur TAK : les appareils ATAK, WinTAK, TAKX et iTAK s'y connectent pour partager positions, marqueurs, chat, fichiers et vidéo. La console est organisée en sections dans la barre du haut (Tableau de bord, Personnes, Données, Messages, Serveur), et les pages de chaque section sont sur la ligne en dessous.

Premières étapes

  1. Changez le mot de passe admin : sur Utilisateurs, cliquez sur Mot de passe sur admin.
  2. Créez des groupes sur Groupes, par exemple Cyan et Command. Les appareils ne voient que le trafic des groupes qu'ils ont en commun.
  3. Créez des utilisateurs sur Utilisateurs et cochez leurs groupes. Donnez à chaque personne son propre utilisateur, pour pouvoir couper un appareil sans toucher aux autres.
  4. Vérifiez l'adresse du serveur : sur un serveur local, les paquets et les codes QR utilisent l'adresse à laquelle vous avez ouvert cette console ; ouvrez-la donc à l'adresse qu'utilisent les appareils (pas localhost). Avec Let's Encrypt, ils utilisent l'Hôte public du Tableau de bord.
  5. Connecter un appareil : sur Connexion, créez un code QR pour un utilisateur et scannez-le avec l'appareil photo du téléphone. Voir Connecter des appareils.

Astuces

  • La carte à côté de chaque page montre les appareils en direct. Carte dans la barre du haut l'affiche ou la masque.
  • Vos propres appareils, certificats et mot de passe sont dans Mon compte.
  • Le bouton de thème dans la barre du haut bascule entre Auto (le réglage clair ou sombre de votre appareil), Clair et Sombre.
  • Chaque modification que vous faites est consignée dans le Journal d'audit.

Tableau de bord

L'état du serveur en un coup d'œil : appareils connectés, messages, problèmes à traiter et mises à jour.

  • Problèmes, en haut, liste tout ce qui ne va pas : un disque plein, des certificats sur le point d'expirer, un lien de fédération coupé.
  • Serveur affiche la version, l'adresse qu'utilisent les appareils (Hôte public) et les ports.
  • Mises à jour d'EdgeTAK : Rechercher des mises à jour, puis Installer. EdgeTAK redémarre tout seul ; les appareils se reconnectent d'eux-mêmes. Ne cochez Inclure les préversions que sur des serveurs de test.
  • Clients connectés liste chaque appareil avec son utilisateur, ses groupes et sa connexion. Vous pouvez en déconnecter un d'ici.

État

Des graphiques de la dernière heure aux dernières 24 heures : processeur, mémoire, disque, réseau, température (sur un Raspberry Pi), appareils connectés, messages et bande passante vidéo, avec des avertissements en cas de disque plein, de surchauffe ou de messages perdus.

Le tableau Appareils liste pour chaque appareil sa batterie (et la vitesse à laquelle elle se vide), son dernier rapport, son fix GPS et sa connexion, les pires problèmes en premier. Servez-vous-en pour repérer un téléphone presque à plat avant qu'il ne décroche.

Utilisateurs

Tous ceux qui se connectent : les appareils des personnes, la console et la page de compte.

Ajouter un utilisateur

  1. Saisissez un nom d'utilisateur et un mot de passe (8 caractères ou plus).
  2. Cochez ses groupes. Aucun groupe signifie __ANON__, partagé avec les appareils anonymes.
  3. Ne cochez Administrateur que pour les personnes qui gèrent le serveur.
  4. Créer, puis connectez son appareil avec QR sur sa ligne.

Les boutons de chaque utilisateur

  • Groupes : quels groupes, et dans quel sens : entrée + sortie (le cas habituel), entrée (reçoit seulement) ou sortie (envoie seulement). Les changements atteignent aussitôt les appareils connectés.
  • Mot de passe en définit un nouveau. Rendre administrateur / Retirer l'administration change son rôle.
  • Désactiver le coupe aussitôt (connexions, certificats, appareils connectés) mais garde le compte ; Activer rétablit le tout. Préférez-le à Supprimer.
  • QR crée un code QR qui connecte son téléphone (voir Connecter des appareils). Paquet télécharge un paquet de connexion ; Émettre un .p12 un certificat pour les clients configurés à la main.
  • Imprimer une feuille de QR… (au-dessus de la liste) imprime une carte QR étiquetée pour chaque utilisateur choisi ou pour tout un groupe.

Aussi sur cette page

  • Connexion en deux étapes pour votre propre compte : après le mot de passe, un code d'une application d'authentification. Les applications TAK ne sont pas concernées.
  • Connexion par annuaire (LDAP / Active Directory) : les personnes se connectent avec leur compte d'annuaire, et les groupes de l'annuaire deviennent des groupes EdgeTAK. Tester ces paramètres avant d'enregistrer.

Groupes et profils d'appareil

Les groupes décident qui voit quoi : un appareil reçoit le trafic envoyé aux groupes où il est en entrée, et son propre trafic part vers les groupes où il est en sortie. Les utilisateurs peuvent activer et désactiver des groupes sur leur appareil avec les Channels d'ATAK.

  • Créer un groupe avec un nom et une description ; les membres se définissent sur Utilisateurs ou avec le bouton du groupe ici.
  • Supprimer un groupe le retire de ses membres.

Profils d'appareil

Des réglages et fichiers envoyés aux appareils des membres d'un groupe (ou de tous les utilisateurs) : réglages ATAK (clé, type et valeur), fichiers .pref, APK de plugins, sources de cartes et calques.

  • Les appareils les reçoivent lors de leur configuration, puis à chaque connexion si le profil a changé.
  • Envoyer maintenant atteint les appareils déjà connectés. Télécharger montre exactement ce que reçoivent les appareils.

Événements

Une opération temporaire (une recherche, un exercice, une course) avec son propre groupe et, si vous le souhaitez, une mission Data Sync. Les gens la rejoignent en scannant un seul code QR, et tout est nettoyé à la fin.

  1. Nouvel événement : un nom, sa date de fin, et la façon dont les gens le rejoignent :
    • Chaque personne s'inscrit : le code QR ouvre une page d'inscription ; chaque personne choisit un nom et obtient son propre compte (limitez leur nombre avec nombre maximal de personnes).
    • Un compte partagé : le code QR connecte ATAK tout de suite ; tous les appareils utilisent le même compte. Le plus rapide pour les arrivées sans inscription préalable.
  2. Affichez le code QR, ou Imprimer une feuille d'accès à afficher au point d'accueil.
  3. À la fin de l'événement (à l'heure fixée, ou avec Terminer maintenant), ses comptes sont supprimés, leurs appareils déconnectés et son groupe retiré. La mission est conservée pour le bilan.

Prolonger change sa date de fin. Paquet fournit un paquet de connexion pour le compte partagé.

Inscriptions

Laissez les gens créer eux-mêmes leur compte sur la page d'inscription, au lieu de créer chacun vous-même.

  • Liens d'invitation : choisissez les groupes, combien de personnes peuvent l'utiliser (0 = sans limite) et sa durée de validité, puis partagez le lien ou son code QR. Quiconque l'a obtient aussitôt un compte dans ces groupes.
  • Inscription sans invitation : Désactivée (invitations seulement, par défaut), Approbation (les demandes attendent sous Demandes en attente que vous les approuviez) ou Ouverte (quiconque joint le serveur). N'utilisez Ouverte que là où vous acceptez que n'importe qui rejoigne.

Après l'inscription, les gens voient un code QR qui connecte leur téléphone, et des paquets de connexion pour chaque application.

Certificats

Les appareils se connectent avec un certificat émis par EdgeTAK lors de leur configuration. Cette page les liste tous.

  • Révoquer le certificat d'un appareil perdu : il est déconnecté et ne peut plus se reconnecter. Les autres appareils de l'utilisateur continuent de fonctionner.
  • Certificats du serveur indique quand l'AC, le certificat du serveur et un éventuel certificat Let's Encrypt expirent, et comment chacun se renouvelle.
  • Les certificats d'appareil sont signalés avant leur expiration (30 jours par défaut) ; réglez ici la durée de validité des nouveaux. Un appareil se renouvelle en se configurant de nouveau (un nouveau code QR ou paquet).

Paquets de données

Les fichiers partagés par le serveur : ce que les appareils envoient avec Send → Server d'ATAK, et ce que vous envoyez ici. Chacun est visible par les groupes de celui qui l'a envoyé.

  • Envoyez, recherchez, téléchargez et supprimez des paquets.
  • Afficher sur la carte dessine les marqueurs, itinéraires, formes et tout KML, KMZ ou GeoJSON d'un paquet sur la carte de la console.
  • Pour pousser un paquet vers les appareils, utilisez Envoyer.

Missions (Data Sync)

Les missions Data Sync sont des espaces de travail partagés : des éléments de carte et des fichiers que l'appareil de chaque abonné garde synchronisés, avec les changements poussés en direct. Elles sont généralement créées dans ATAK, WinTAK ou iTAK (Data Sync) ; cette page les gère.

  • Consultez les abonnés et leurs rôles, les éléments et fichiers, l'historique des changements et les invitations.
  • Afficher sur la carte dessine les éléments d'une mission ; Exporter la télécharge.
  • Une mission est visible par les groupes pour lesquels elle a été créée. Un événement peut en créer une pour son groupe.

Cartes : dessins et cartes hors ligne

Dessins

Dessinez des marqueurs, itinéraires, zones et cercles sur la carte de la console ; ils apparaissent sur la carte des appareils comme des éléments placés par un coéquipier, pour tous les appareils ou des groupes choisis. Les appareils éteints les reçoivent à leur connexion ; modifier ou supprimer un dessin met à jour les appareils.

Cartes hors ligne

  1. Créez ou procurez-vous un fichier MBTiles de tuiles raster (QGIS, MOBAC, gdal et autres).
  2. Envoyez-le ici, ou copiez les gros fichiers dans le dossier maps du serveur (indiqué sur la page) et Réanalyser le dossier.
  3. Il devient un fond de carte dans la console, et les appareils ATAK le reçoivent comme source de carte à leur connexion : les cartes fonctionnent sans internet.

Vos propres sources de tuiles (et les fichiers .xml de sources de cartes ATAK) sont sous Sources de cartes sur la carte elle-même ; cochez Envoyer aux appareils ATAK pour en ajouter une à la liste de cartes des appareils.

Calques

Envoyez des calques (superpositions cartographiques : limites, secteurs de recherche, itinéraires, points) aux appareils sans faire circuler de fichiers à la main.

  1. Importez un fichier KML, KMZ ou GeoJSON, nommez-le et choisissez les groupes dont les appareils le reçoivent (aucun = tous les appareils).
  2. Les appareils connectés le reçoivent tout de suite sous forme d'un seul calque dans l'Overlay Manager d'ATAK ; les appareils éteints le reçoivent à leur connexion.
  3. Remplacer le fichier envoie une nouvelle version qui remplace l'ancienne ; Arrêter l'envoi le met en pause.

On ne peut pas demander à ATAK de retirer un calque : Supprimer ne fait donc qu'arrêter l'envoi par EdgeTAK ; les gens le retirent sur leur appareil.

Plugins

Un serveur de mises à jour pour ATAK, comme celui de tak.gov : les appareils installent et mettent à jour plugins et applications depuis l'écran Plugins d'ATAK.

  • Envoyez des APK de plugins ou d'applications. Des versions pour plusieurs versions d'ATAK peuvent coexister ; chaque appareil reçoit celle de sa version (ou la plus proche plus ancienne).
  • Les appareils sont dirigés automatiquement vers ce serveur de mises à jour (Diriger les appareils vers ce serveur de mises à jour).
  • Si une application apparaît comme un plugin dans ATAK (ou l'inverse), utilisez Traiter comme application / Traiter comme plugin.
  • Plugins de tak.gov : liez un compte tak.gov, choisissez la version d'ATAK, et Ajouter des plugins sans les télécharger vous-même.

Vidéo

Des flux vidéo pour le Video Player d'ATAK et de WinTAK, limités par groupe.

  • Publication : envoyez un flux avec n'importe quel nom d'utilisateur et mot de passe EdgeTAK, par ex. rtsp://USER:PASSWORD@server:8554/NAME (RTMP et SRT fonctionnent aussi). Il apparaît aussitôt sur cette page.
  • Enregistrer comme flux le nomme, choisit qui peut le regarder et peut lui donner une position sur la carte (un marqueur de caméra sur les appareils).
  • Visionnage : sur les appareils, ouvrez Video Player et importez depuis le serveur ; dans la console, Regarder.
  • Publier sans connexion sert aux caméras qui ne savent pas s'authentifier : ne l'autorisez que pour des flux nommés.
  • Enregistrement (désactivé par défaut) conserve les flux pendant un nombre de jours défini ; lisez-les ou téléchargez-les sous Enregistrements.
  • La carte MediaMTX met à jour ou redémarre le serveur vidéo.

Envoyer

Envoyez un message de chat ou un paquet de données à tout le monde, à des groupes choisis ou à des appareils choisis.

  • Choisissez les destinataires, puis écrivez le message ou choisissez un paquet de données (y compris des paquets de réglages .pref).
  • Contact du serveur : le serveur peut apparaître sur les appareils comme un contact QG ; les réponses à ses messages arrivent dans la Boîte de réception.
  • Envois programmés : un message ou un paquet à une heure fixée, une fois ou de façon répétée (toutes les quelques heures, chaque jour, en semaine, des jours choisis).
  • Envoyé liste ce qui est parti.

Journal du chat

Désactivé par défaut. Une fois activé, il enregistre le chat qui passe par le serveur (All Chat Rooms, chats d'équipe et de groupe, messages individuels) pour les retours d'expérience.

Recherchez-y, filtrez par conversation, expéditeur et date, et exportez en CSV ou JSON. La durée de conservation des messages se règle sous Paramètres → Conservation des données.

Connecter des appareils

Les façons de connecter un appareil au serveur, de la plus simple à la moins simple.

Code QR (ATAK)

  1. Sur cette page (ou avec QR à côté d'un utilisateur sur Utilisateurs), choisissez l'utilisateur, la durée de validité du code, et s'il est pour un seul appareil.
  2. Créer le code QR et scannez-le avec l'appareil photo du téléphone. ATAK s'ouvre et se connecte en tant que cet utilisateur. Personne ne saisit de mot de passe.
  • Avec Let's Encrypt, ATAK s'enrôle avec le code. Sur un serveur local, il télécharge à la place un paquet de connexion (par le port 8080) contenant un certificat ; utilisez ces codes sur des réseaux de confiance.
  • Le code vaut un mot de passe jusqu'à son expiration : ne le publiez pas. Les codes Un seul appareil cessent de fonctionner 10 minutes après leur première utilisation.
  • Téléphone perdu ou nouveau : cochez Nouveau téléphone : remplacer ses appareils. Quand le nouveau téléphone scanne le code, les autres appareils de l'utilisateur sont déconnectés (vous confirmez d'abord ; rien ne se passe avant le scan).
  • Imprimer une feuille de QR… crée une carte par utilisateur pour un briefing.
  • iTAK : choisissez iTAK sous Application. Avec Let's Encrypt, iTAK scanne le code (Settings → Network → Servers → + → Scan QR), puis se connecte et s'enrôle tout seul avec le code à usage unique qu'il contient. Sur un serveur local, l'appareil photo de l'iPhone télécharge à la place un paquet, que vous ajoutez dans iTAK avec Upload Server Package.

La liste des codes

Mise à jour en direct. Appareils montre ce que chaque code a configuré : en ligne avec l'indicatif, hors ligne, révoqué ou jamais connecté. Si un téléphone déjà connecté à ce serveur sous une autre identité a scanné le code, redémarrez ATAK. Révoquer arrête un code ; Déconnecter coupe aussi les appareils qu'il a configurés.

Autres façons

  • Paquet de connexion (toute application) : téléchargez-le ici et importez-le sur l'appareil. Avec un utilisateur choisi, il contient un certificat à son nom : l'application se connecte donc sans identifiants (un par appareil ; révoquez-le sur Certificats). Sans utilisateur, ATAK, WinTAK et TAKX demandent un nom d'utilisateur et un mot de passe puis s'enrôlent. Pour iTAK, choisissez iTAK.
  • Saisie de l'adresse (serveurs avec Let's Encrypt) : ajoutez le serveur dans l'application, activez Use authentication et Enroll for client certificate, puis saisissez le nom d'utilisateur et le mot de passe.
  • La page de connexion des utilisateurs (lien en bas) permet aux gens d'obtenir eux-mêmes leur code QR et leurs paquets.

Aussi ici

  • Historique des positions : enregistrez les traces des appareils (désactivé par défaut) pour les pistes, la relecture et l'export KML/GPX, depuis le bouton Historique de la carte.
  • Sources de cartes : des sources de tuiles envoyées à la liste de cartes des appareils.

Fédération

Reliez ce serveur à un TAK Server ou à un autre EdgeTAK, pour que les appareils des deux côtés voient les positions, marqueurs et chats les uns des autres, et reçoivent les paquets de données les uns des autres.

Se connecter à un TAK Server

  1. Se connecter à un serveur, saisissez son adresse et choisissez le mode d'authentification : un certificat (port 9001 ; le TAK Server doit faire confiance à l'AC d'EdgeTAK, ce que fait Faire en sorte que le serveur TAK fasse confiance à EdgeTAK avec son identifiant admin) ou un jeton de fédération (port 9002).
  2. Son AC : L'obtenir du serveur, vérifiez l'empreinte avec son administrateur, et faites-lui confiance.
  3. Enregistrez. La liste montre l'état de la connexion et le nombre de messages.

Laisser d'autres serveurs se connecter

Activez Autoriser d'autres serveurs à se connecter sur le port 9001. Un serveur qui se connecte attend sous En attente d'approbation ; vérifiez son empreinte, puis Approuver.

Sur un TAK Server avec LDAP, donnez au fédéré EdgeTAK l'un des groupes de vos utilisateurs (Groupes du serveur TAK pour EdgeTAK), sinon aucun trafic ne passe.

Paramètres

  • Alertes d'urgence : quand quelqu'un appuie sur le bouton d'urgence d'ATAK, chaque console ouverte affiche une bannière rouge et déclenche une alarme jusqu'à l'acquittement. Le journal est ici.
  • Alertes de perte de contact : une alerte orange avec la dernière position quand un appareil cesse d'émettre (pas quand quelqu'un se déconnecte volontairement). Décochez pour désactiver.
  • Géobarrières : dessinez une zone ou un cercle et recevez une alerte quand des appareils y entrent ou en sortent.
  • Logo : Envoyer un logo… remplace la marque ◆ par le logo de votre organisation dans la console, sur les pages de connexion, d'inscription et de compte et sur les feuilles de QR imprimées, et en tire les icônes de l'onglet du navigateur et de l'application installée. PNG, JPEG ou WebP ; Retirer rétablit celui par défaut.
  • TCP non chiffré : activez ou désactivez le port 8087 (non chiffré, appareils anonymes qui ne voient que __ANON__) sans redémarrage. Le désactiver ferme le port et déconnecte ces appareils. Si le serveur a un pare-feu, ouvrez-y aussi le 8087 (sudo ufw allow 8087/tcp).
  • ZeroTier : placez le serveur sur un réseau ZeroTier pour que les appareils le joignent de n'importe où sans ouvrir de ports sur le routeur. Installer ZeroTier, rejoignez votre réseau par son ID, puis autorisez le nœud de ce serveur dans ZeroTier Central. Utiliser pour les appareils à côté de son adresse ZeroTier fait pointer les paquets et codes QR de la page Connexion vers celle-ci.
  • Accès à distance (FRP) : joignez le serveur de n'importe où sans ouvrir de ports sur le routeur. Il vous faut un serveur FRP (frps) sur un VPS ou un service de relais. Configurer l'accès à distance, collez ou chargez son frpc.toml (ou Partir d'un modèle et renseignez le serveur et le jeton), enregistrez et Connecter. EdgeTAK télécharge frpc et le maintient en marche. Utiliser pour les appareils fait pointer les paquets et codes QR vers le serveur FRP.
  • Avions et navires : les avions en direct (ADS-B, depuis adsb.lol, adsb.fi ou une URL personnalisée : le aircraft.json de votre propre récepteur ou une autre API, avec sa clé d'API dans un en-tête ou dans l'URL) et les navires (AIS, depuis aisstream.io avec une clé d'API gratuite) autour d'une zone, envoyés aux appareils sous forme de marqueurs. Définissez le centre (ou Utiliser le centre de la carte), puis pour chaque flux son rayon, s'il faut l'envoyer et à quels groupes. Ils s'affichent aussi sur la carte de la console comme calques Avions et Navires.
  • Protection de la connexion : bloque une adresse après trop de mots de passe erronés. Ajoutez vos propres réseaux à Ne jamais bloquer, et débloquez les gens ici.
  • Conservation des données : combien de temps garder les paquets, missions, messages, le journal du chat et le journal d'audit. Elle montre ce qui serait supprimé avant que vous n'enregistriez.
  • Sauvegarde et restauration : téléchargez une sauvegarde (ou programmez-les) et restaurez-en une sur ce serveur ou sur un nouveau.

Webhooks

Envoyez des alertes vers Discord, Slack, Microsoft Teams, ntfy (notifications sur téléphone) ou n'importe quelle URL, pour que les gens soient prévenus même console fermée.

  1. Obtenez une URL de webhook auprès du service (la page donne les étapes pour chacun).
  2. Ajouter un webhook, choisissez le service, collez l'URL et choisissez les alertes : urgences, géobarrières, perte de contact, inscriptions, changements d'administration, état du serveur, connexions bloquées.
  3. Enregistrez et appuyez sur Envoyer un test.

Limitez un webhook à des groupes pour n'être prévenu que des appareils de ces utilisateurs.

Journal d'audit

Chaque modification faite par un administrateur, avec qui, d'où, quoi et si elle a réussi ; ainsi que les connexions, les connexions échouées, les adresses bloquées, les enrôlements d'appareils et les codes QR utilisés. Les mots de passe et les clés ne sont jamais enregistrés.

Recherchez-y, n'affichez que les échecs, et téléchargez-le en CSV. Sa durée de conservation se règle sous Paramètres → Conservation des données (indéfiniment par défaut).

Vider le journal… supprime toutes les entrées après confirmation ; téléchargez d'abord un CSV si vous en avez besoin. L'effacement lui-même reste comme première entrée du nouveau journal.

Simulateur

Test de charge : des appareils simulés se connectent comme ATAK, se déplacent et envoient des positions (et du chat), pour voir comment le serveur tient le coup avant un gros événement.

  • Choisissez combien d'appareils, à quelle vitesse ils arrivent, à quelle fréquence ils émettent et combien de temps dure le test, puis suivez en direct les connexions, les événements par seconde, le temps de relais, le processeur et la mémoire.
  • Ils utilisent un compte temporaire dans le groupe Simulateur, pour que les vrais appareils ne les voient pas ; il est supprimé à la fin du test.
  • Le trafic croît avec le carré du nombre d'appareils ; commencez petit sur un Raspberry Pi. Désactivez d'abord l'historique des positions si vous ne voulez pas qu'ils soient enregistrés.

Mon compte et connexion en deux étapes

Tout le monde se connecte sur la même page : les administrateurs arrivent sur cette console, les utilisateurs sur leur page de compte, où ils obtiennent un code QR pour leur téléphone et des paquets de connexion, voient leurs appareils et certificats, révoquent le certificat d'un appareil perdu et changent leur mot de passe.

Connexion en deux étapes (facultative) : activez-la depuis la page de compte (ou pour vous-même, sur Utilisateurs), scannez le code avec une application d'authentification, et conservez les codes de récupération. Les applications TAK continuent d'utiliser le mot de passe. Si quelqu'un perd son téléphone, un administrateur peut Réinitialiser la 2FA sur Utilisateurs.

Dépannage

  • Un appareil ne se connecte pas : vérifiez que l'Hôte public du Tableau de bord est une adresse que le téléphone peut joindre, et que les ports sont ouverts (8089 pour les appareils, 8443 pour l'API, 8446 pour la configuration). L'utilisateur est-il désactivé, ou le certificat révoqué ?
  • Un code QR affiche « jamais connecté » : le téléphone était probablement déjà connecté à ce serveur sous une autre identité. Redémarrez ATAK (ou supprimez le serveur dans ATAK et scannez de nouveau).
  • Les appareils ne se voient pas : ils ont besoin d'un groupe en commun (en entrée d'un côté, en sortie de l'autre). Vérifiez les Groupes de chaque utilisateur.
  • Quelqu'un est bloqué : voir Bloquées maintenant sous Paramètres → Protection de la connexion.
  • Voir ce que fait un appareil : réglez log_level sur debug et suivez le journal du serveur (journalctl -u edgetak -f) ; chaque requête y est listée.
  • Le manuel complet est le README sur GitHub.
