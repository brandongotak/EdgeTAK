Webhooks

        
Send alerts to Discord, Slack, Microsoft Teams, ntfy (a phone app) or any URL, so people hear about them with the console closed: emergencies, geofence alerts, lost contact, alerts ending and sign-ups. Each webhook can be limited to devices in some groups. At most 20 messages a minute go to each; more are counted in the next one.

        

          
WebhookAlertsGroupsLast sent

          
        

      

      

        
How to set up a webhook

        
Pick the service your team already uses. Each gives you a web address (the webhook URL) that EdgeTAK posts alerts to; paste it into Add webhook, choose the alerts, save, then press Send test and check the message arrives. Treat the URL like a password: anyone who has it can post to your channel.

Simulator

        
Load-test this server with simulated TAK devices. Each one connects to the TLS streaming port like ATAK, walks around the map's centre sending position reports (and chat, if you like), and reads everything the server relays. They sign in as a temporary account in the group below (Simulator keeps them away from real devices), which is removed when the run ends. They run on this machine, sharing its CPU with the server; for load from another computer use edgetak sim (below).

Emergency alerts

        
When someone presses the emergency button in ATAK (911 Alert, Ring The Bell, In Contact, Geo-fence Breached or a custom alert), every open console shows a red banner and sounds an alarm until an admin acknowledges it. The alert stays until the device cancels it or an admin dismisses it.

Lost contact alerts

        
An amber alert, with the last known position, when a device stops reporting: its connection went silent or dropped, or it stays connected without sending a position. A device that signs off (turns its server connection off, quits ATAK, shuts down) closes its connection itself, so it doesn't alert and is only listed below. A device that comes back within the grace period (switching networks) doesn't alert either, and alerts end by themselves when the device is back.

Login protection

        
An address that fails to sign in with a password too often is blocked from password sign-ins for a while: the console, account page, device enrollment, the update server and ATAK's username sign-in. Devices connected with their certificate and people already signed in carry on, so one person mistyping on a shared network doesn't cut off a team. This machine is never blocked. Failed sign-ins and blocks are in the audit log; a webhook with Blocked sign-ins ticked hears about each block.

Backup and restore

        
A backup holds everything needed to bring this server back: users, groups, the CA and certificates (so devices reconnect without enrolling again), settings, device profiles, federation, data packages, missions, plugins and the chat log. It includes the CA's private key and password hashes: keep it as safe as the server. Keep a copy somewhere other than this server.

The data it replaces is kept in .pre-restore in the data folder until the next restore.

Directory sign-in (LDAP / Active Directory)

        
People sign in with their directory username and password everywhere: the console, the account page, and ATAK, iTAK and WinTAK enrollment. Their directory groups become EdgeTAK groups, updated at each sign-in and every 30 minutes. Local accounts, yours included, keep working, also when the directory is down. A local account with the same name as a directory user wins.

An event is a temporary operation with its own group and Data Sync mission. People join by scanning its QR code. When it ends, every event account is erased: certificates revoked, devices disconnected. Its group is removed and its mission is kept for review.

ATAK plugins and apps

        
Devices install and update these from ATAK's Plugins screen, which lists what this server offers (ATAK's update server). ATAK runs plugins built for its own version or an older one, so each device is offered the build for the nearest ATAK version at or below its own (a 5.6.0 plugin on ATAK 5.7). A newer build of a plugin for the same ATAK version replaces the old one.

Import an overlay

        
Import a KML, KMZ or GeoJSON file once (boundaries, search sectors, routes, points) and every device in the chosen groups gets it as a map overlay it can show or hide in ATAK's Overlay Manager. Devices that are off get it when they next connect. Replacing the file sends the new version, which replaces the old one on devices.
